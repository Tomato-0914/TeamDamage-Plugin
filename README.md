# TeamDamage-Plugin

TRSS-Yunzai / Miao-Yunzai 原神队伍伤害插件，基于 [FanSky_Qs](https://github.com/AFanSKyQs/FanSky_Qs) 精简而来，只保留队伍伤害功能，并支持自定义手法。

## 前置要求

- [TRSS-Yunzai](https://github.com/TimeRainStarSky/Yunzai) 或 [Miao-Yunzai](https://gitee.com/yoimiya-kokomi/Miao-Yunzai)
- [miao-plugin](https://gitee.com/yoimiya-kokomi/miao-plugin)（读取角色面板数据及渲染资源）

## 安装

在云崽根目录下：

```
git clone --depth=1 https://github.com/Tomato-0914/TeamDamage-Plugin.git ./plugins/TeamDamage-Plugin/
```

## 功能

| 指令 | 说明 |
|---|---|
| `#队伍伤害钟离，阿贝多，可莉，魈` | 使用已绑定的 uid 计算队伍伤害（最多 4 人，只写一个角色时按单人计算） |
| `#队伍伤害100000000钟离，阿贝多` | 指定 uid（9~10 位数字）计算 |
| `#队伍伤害@张三 钟离，阿贝多` | 计算被艾特用户的队伍 |
| `#队伍伤害雷九` / `#队伍伤害纳塔战舰` | 使用队伍简写或其别名（见下文「队伍简写」） |
| `#队伍伤害预设列表` | 查看全部队伍预设（角色、手法、别名）：一个合并转发里包含「自定义预设」「默认预设」两个合并转发，按大版本分类 |
| `#队伍伤害钟离，班尼特，香菱，行秋 钟离长e，班尼特eq，香菱q，e` | 自定义手法 |
| `#队伍伤害香菱换六命换精5，行秋，班尼特` | 换装模拟（见下文） |
| `#队伍伤害帮助` | 以图片形式查看全部写法 |
| `#队伍伤害设置` | 查看设置；`#队伍伤害设置全队满暴 开启`、`#队伍伤害设置提示撤回 5` 等修改（主人） |
| `#更新队伍伤害` / `#强制更新队伍伤害` | 更新插件并自动重启（主人）；强制更新会丢弃本地改动 |

计算前需先通过 `#更新面板` 获取对应角色的面板数据。出图前会先发一条队伍、手法、换装的提示，默认 5 秒后自动撤回（可在锅巴「基础设置」中关闭提示或修改撤回时间）。

旅行者可写 `旅行者` / `空` / `荧` / `草主` / `雷主` 等，按面板里当前的元素计算（面板只保存最后一次更新时的元素，写的元素与面板不一致时会提示切换后再更新面板，也可以用换装 `旅行者换雷` 按当前面板估算）；冰主提瓦特小助手暂不支持。

结果图依次展示：

- **顶部**：输出总伤（全图最大的数字）；下方评级横幅显示伤害评级与全服排名进度条（超过全服百分比）；数据卡为 DPS、输出轴长、伤害次数、最高一击
- **队伍与输出占比**：每个角色的命座、等级、武器与圣遗物（右下角角标为武器精炼 / 圣遗物件数，4~5 件显示 4，2~3 件显示 2）、天赋（10 级及以上金色）、双暴、关键属性、充能、剩余能量、输出占比
- **伤害时间分布**：每秒期望伤害，按角色堆叠，最高一秒标注数值
- **操作手法**（标题旁标注自定义 / 默认）、**伤害过程**（两栏排列，最高一击高亮）、**Buff 情况**（两栏排列）

背景取主 C 立绘，配色随主 C 元素变化。

### 自定义手法

队伍写完后接手法，从第一个能识别为动作的词开始都算手法。不写手法时使用小助手的默认手法。

也可以不写队伍、直接写手法，队伍按角色在手法中首次出现的顺序自动识别（此时第一个动作必须写角色名）：

```
#队伍伤害仆人e重击 希诺宁eaa 尼可eq 奶奶eq 仆人qea1a2a3a4a5a6
```

| 写法 | 含义 |
|---|---|
| `e` / `战技` | 元素战技 |
| `短e` / `点e` / `e1` | 短按元素战技 |
| `长e` / `长按e` / `e2` | 长按元素战技 |
| `q` / `大招` / `爆发` | 元素爆发 |
| `重击` / `z` / `zj` | 重击 |
| `下落攻击` / `下落` / `xl` | 下落攻击（如魈） |
| `a` / `普攻` / `平a` | 普攻，紧跟在同一角色普攻后时接续下一段（`aaa` = 第 1~3 段），否则为第 1 段 |
| `a1` ~ `a9` | 普攻第 N 段 |
| `跳跃` / `跳` / `k` | 跳跃（可打断普攻连段，之后的 `a` 从第 1 段开始） |
| `闪避` / `闪` / `冲刺` / `s` | 闪避（结果图中显示为「冲刺」） |
| `等0.5` / `等待1s` / `d0.5` / `D1` | 等待（0.1 ~ 20 秒） |

- 动作前写角色名（支持别名）指定由谁执行，**省略角色名则沿用上一个角色**；第一个动作不写角色名时默认为队伍第一位
- 字母不区分大小写：`e` / `E`、`z` / `Z` 均可
- 同一角色可连写：`班尼特eq` = 班尼特 E 接 Q，`胡桃azk*3` = 胡桃三次普攻重击跳跃
- 可重复：`a1*3`、`重击3次`、`e2x2`
- 至少需要 2 个技能动作
- 也可配合队伍简写：`#队伍伤害雷九 雷神e，九条裟罗e，万叶e，班尼特q，雷神q`

如果某个动作该角色无法使用（例如普攻段数超出），小助手会拒绝计算，去掉该动作即可。

### 换装模拟

在角色名后面接「换xx」，可以叠加，用当前面板估算换装后的伤害：

| 写法 | 含义 |
|---|---|
| `换满命` / `换六命` / `换6命` / `换命座6` / `换c6` | 命座 0~6（满命 = 6 命）；跨过 3/5 命时对应天赋自动 +3（小助手不会自己加） |
| `换精5` / `换精五` / `换精炼五` / `换满精` / `换r5` | 武器精炼（满精 = 精 5） |
| `换天赋101313` / `换天赋10-13-13` / `换天赋999` | 天赋最终等级（普攻 / E / Q），优先于换命座带来的天赋变化 |
| `换七命` / `换九命` | 7 命 = 6 命 + 95 级（需 1 个无主的命星），9 命 = 6 命 + 100 级（共需 3 个），没有 8 命；同时写了等级时以等级为准 |
| `换90级` / `换100级` | 角色等级 1~100；只影响等级相关的系数（如反应伤害），面板的生命、攻击等不会随之变化 |
| `换护摩之杖` / `换护摩` / `换专武` | 换武器，支持 miao 的武器别名 |
| `换4千岩` / `换绝缘` / `换2追忆2如雷` | 换圣遗物套装，不写件数按 4 件 |
| `旅行者换雷` / `空换草元素` | 旅行者换元素（冰主除外）：元素伤害加成挪到新元素（视为换了对应元素杯），没写换天赋时按新元素的 3/5 命规则重算天赋 |

```
#队伍伤害雷神换专武换六命，九条裟罗，万叶，班尼特换精5
```

- 小助手不计算武器白值和副词条，换武器时插件按 miao 的武器数据在本地换算（攻击% 类按近似折算）
- 换套装只换套装效果，圣遗物词条沿用当前面板；原套装两件套的属性加成已算进面板，所以主要体现的是四件套效果
- 武器类型不对时会提示并跳过，其余换装照常生效
- 队伍预设的角色里也可以写换装；也可以在简写后面临时换装，预设手法照常生效：`#队伍伤害雷九 雷神换六命 班尼特换精5`
- 只写手法、不写队伍时，换装可以写在手法里任意位置，会接到对应队员上：`#队伍伤害芙宁娜eq 爱可菲eq 丝柯克qe 爱可菲换1命`

### 队伍简写

插件自带的默认预设在 `config/default_SimpleTeamArr.yaml`，随插件更新，请勿修改。除了雷九、胡行钟香等经典队伍，也收录了玛希茜班（纳塔战舰）、仆希茜班（仆人战舰）、丝爱芙莫（丝柯克冰队）、菲机少砂（月感电）、兹少叶莉（月结晶）、法杜布尼（魔导战舰）、奈菈少妮（运钞车）、那芙希万（枫丹战舰）、瓦玛夏伊（瓦雷莎超载）等较新的配队，括号内为可用的别名。

自定义预设存放在 `config/SimpleTeamArr.yaml`，**只需写新增或要覆盖的队伍**，修改即时生效：

- **锅巴**：安装 [Guoba-Plugin](https://gitee.com/guoba-yunzai/guoba-plugin) 后，在锅巴后台「插件管理 → 队伍伤害」中增删自定义预设（简写、角色、手法、别名），保存时会校验角色名和手法；与默认预设完全相同的条目会自动跳过
- **手动**：在 `config/` 下新建 `SimpleTeamArr.yaml`，格式同默认文件

每个预设可以带一套手法（YAML 中的 `combo` 字段，写法同指令）：留空走小助手默认手法，填写后使用该预设时自动套用；指令里另写了手法时以指令为准。

```yaml
雷九: { alias: [ 雷九万班 ], chars: [ 雷电将军, 九条裟罗, 枫原万叶, 班尼特 ], combo: 雷神e，九条裟罗e，万叶e，班尼特q，雷神q }
```

自定义预设与默认预设同名时以自定义为准，其余默认预设照常可用；删除自定义文件即只使用默认预设。

发送 `#队伍伤害预设列表` 可以直接在群里查看全部预设：一个合并转发里包含两个合并转发，自定义预设在前、默认预设在后，各自按队伍成型的原神大版本（队员中最新角色所在的版本）分类；被同名自定义预设覆盖的默认预设会标注出来。

### 插件设置

在锅巴「插件管理 → 队伍伤害 → 基础设置」中修改，或在 `config/` 下新建 `config.yaml`，只写要修改的项（默认值见 `config/default_config.yaml`）：

| 设置 | 默认 | 说明 |
|---|---|---|
| `sendTips` | `true` | 计算前是否发送提示信息；关闭后只在有换装警告时发送 |
| `tipsRecall` | `5` | 提示信息自动撤回的秒数，0 为不撤回，最长 120 秒 |

## GCSim 本地计算（测试版）

`#队伍模拟` 不经过提瓦特小助手，在本机用开源模拟器 [GCSim](https://github.com/genshinsim/gcsim)（MIT）计算，写法与 `#队伍伤害` 相同（UID、@、队伍简写、换装都能用），但**必须写手法**（或使用带手法的队伍预设）：

```
#队伍模拟钟离，夜兰，行秋，胡桃 钟离长e，夜兰qe，行秋qe，胡桃e azk*4 q
```

和小助手的区别：

- 没有默认手法、没有伤害评级和全服排名、没有 Buff 列表
- 只跑一次模拟，总伤按每一击的期望伤害（暴击率 × 暴伤）累加；怪物 90 级、10% 抗性，开局满能量，大招不检查能量
- 手法按游戏规则校验，例如单手剑 / 长柄武器普攻最后一段后不能直接重击（`a*5 z` 要写成 `a*4 z`），下落攻击只能在魈 Q 等空中状态下使用
- 剧变反应（超载、感电、扩散等）在输出占比里单独列出；主C满暴 / 全队满暴设置同样生效，且不需要重新计算
- 少数新角色、低星武器 GCSim 暂不支持，会直接提示

### 安装 GCSim

需要自行准备 GCSim 命令行程序，放到插件目录的 `bin/gcsim`（Windows 为 `bin/gcsim.exe`），或在 `config.yaml` 里用 `gcsimPath` 指定路径。用 Go（1.22+）从源码编译：

```bash
git clone --depth=1 https://github.com/genshinsim/gcsim.git
cd gcsim
go build -o ../plugins/TeamDamage-Plugin/bin/gcsim ./cmd/gcsim   # 路径按实际的 Yunzai 目录调整
```

编译出的程序约 40MB，只需编译一次；GCSim 更新角色后重新编译即可。

## 设置

发送 `#队伍伤害设置` 查看，主人可用 `#队伍伤害设置<项目> <值>` 修改，也可在锅巴「基础设置」中修改，即时生效。

| 项目 | 说明 | 默认 |
|---|---|---|
| 伤害过程 | 结果图是否展示伤害过程表 | 开启 |
| 队伍面板 | 结果图是否展示队伍与输出占比 | 开启 |
| 主C满暴 | 输出占比最高的角色按 100% 暴击计算（先算一次找出主 C 再重算，会多请求一次小助手） | 关闭 |
| 全队满暴 | 全队按 100% 暴击计算，开启时主C满暴不再单独生效 | 关闭 |
| 提示信息 | 计算前发送 UID、队伍、手法等提示 | 开启 |
| 提示撤回 | 提示信息自动撤回的秒数（0~120，0 为不撤回） | 5 |

开启满暴时，结果图的输出总伤旁会标注「全队满暴」或「主C满暴·角色名」。怪物等级（90）、怪物抗性（10%）、开局能量与目标类型由提瓦特小助手接口固定，暂不能修改。
